# CSS Practice Project 🎨

A practical project focused on learning and mastering fundamental CSS styling techniques and page structuring.

---

## 💻 About The Project

This repository serves as a hands-on exercise to understand core styling principles and practice separating HTML structure from CSS presentation.
This link 👉🏻https://areby-12.github.io/css.training-/

---

## 🛠️ Tech Stack

* **HTML5** - Page structure and semantic elements.
* **CSS3** - Styling, background images, and layout elements.

---

## 🎯 Key Concepts Applied

* Managing internal and external spacing (Padding & Margin).
* Creating and styling borders around elements.
* Integrating and adjusting background images.
* Designing attractive buttons and links.
